# Hey, I'm Mohamed 👋

I'm a **Security Researcher** focused on **vulnerability research, source-code analysis, and offensive security**.

My research focuses on discovering and understanding vulnerabilities in **web applications, Android applications, and open-source projects**, with an emphasis on understanding the underlying root cause rather than simply identifying security issues.

I also participate in **bug bounty programs** and work on independent security research, including vulnerability discovery, proof-of-concept development, and responsible disclosure.

## 🧪 Vulnerability Research

I enjoy going beyond automated findings and investigating **why a vulnerability exists at the code and architecture level**.

Some areas I actively research:

* Open-source security
* Framework and library vulnerabilities
* Authorization and privilege boundaries
* Input validation and trust boundaries
* Attack-surface discovery
* Source-code driven vulnerability analysis
* Android library security
* Web application internals
* Vulnerability reproduction and PoC development

## 🐛 Bug Bounty

I participate in bug bounty programs and security research across platforms including:

**HackerOne · Bugcrowd · YesWeHack**

My approach is primarily research-driven: understand the application, map its attack surface, identify interesting trust boundaries, and then investigate the underlying security assumptions.
